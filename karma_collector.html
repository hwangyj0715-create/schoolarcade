⚙ 교칙 · 괴물 커스텀

교칙을 편한 형식으로 붙여넣고 분석하면 괴물 단어를 자동으로 뽑아요. 각 괴물에 직접 이미지를 등록할 수도 있어요.

분석 버튼을 누르면 인식된 단어와 점수를 아래에 보여줍니다.
분석된 괴물 항목이 여기에 표시됩니다.

지원 형식 예시:
• 문장: “교복을 착용하지 않으면 벌점 3점”, “지각 시 2점”, “휴대전화를 수업 중 사용하면 3점”
• 키워드: 한 줄에 `교복 미착용`, `지각`, `명찰`처럼 입력하면 기본 1점
• 직접 지정: `교복 미착용|-3` 또는 `지각|2` · 퇴사 항목은 `퇴사|특수`
이미지는 각 항목의 “이미지 넣기”로 추가하며, 이 브라우저에 저장됩니다. 이미지 파일은 자동으로 작게 압축됩니다. 점수는 포획 시 절댓값으로 더해집니다.

게임을 시작하면 입력창이 활성화됩니다.
🎯 조작 방법
① 괴물 위에 표시된 단어를 입력한 뒤 Enter를 누르면 체인을 발사합니다. 띄어쓰기는 넣거나 생략해도 됩니다.
② 벌점 숫자의 절댓값만큼 점수를 얻습니다. (예: -3 → +3점)
③ 퇴사 괴물을 잡아 충전을 모은 뒤, 스페이스바 두 번으로 잠깐 슬로우모션을 발동하세요.
🌊 웨이브 규칙
초반에는 괴물이 적고 천천히 다가옵니다. 30초마다 웨이브가 오르며 괴물의 이동 속도와 등장 빈도가 서서히 증가합니다. 괴물이 중앙 캐릭터에 닿으면 내구도가 1 감소합니다. 내구도가 0이 되면 게임이 끝납니다.
